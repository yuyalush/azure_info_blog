今週のハイライト
- OpenAIの最新フロンティアモデルシリーズがMicrosoft Foundryで一般公開。
- Azureのレジリエンシー進化についての新しいブログ記事を公開。

## AI・機械学習
### Frontier models and production agents: Advancing Microsoft Foundry for the agentic era
OpenAIの最新フロンティアモデルシリーズと、アジア太平洋データゾーン、製品エージェント機能がMicrosoft Foundryで一般公開されました。これにより、より高度なAIシステムの構築と運用が可能になります。詳細は[こちら](https://azure.microsoft.com/en-us/blog/frontier-models-and-production-agents-advancing-microsoft-foundry-for-the-agentic-era/)をご覧ください。

## コンピューティング
### Built to bounce back: How Azure resiliency evolved
Azureのレジリエンシーに関する進化についての記事が公開されました。クラウド環境におけるシステムの適応、回復、機能維持の重要性が強調されています。これにより、実世界の制約内での運用がよりスムーズになります。詳しくは[こちら](https://azure.microsoft.com/en-us/blog/built-to-bounce-back-how-azure-resiliency-evolved/)を参照してください。

## セキュリティ
### External key management for Azure Managed HSM is now in public preview
Azure Key Vault Managed HSMの外部キー管理機能がパブリックプレビューに移行しました。この機能により、暗号化キーの強力な管理が可能となり、ユーザーはキーの生成と保存を一元管理できます。Microsoftはキー素材にアクセスできず、使用権限を完全に制御できます。詳細は[こちら](https://azure.microsoft.com/en-us/blog/external-key-management-for-azure-managed-hsm-is-now-in-public-preview/)をご覧ください。
