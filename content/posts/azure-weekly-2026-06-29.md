今週のハイライト
- Azure Chaos Studioがアプリケーションのレジリエンスを検証できる機能を提供
- Azure IaaSの長期的なコスト効率を考慮したインフラ設計のガイド
- Microsoft FoundryでClaudeが一般提供開始、NVIDIAの最新ハードウェアを活用

## AI・機械学習
- **Claude in Microsoft Foundryが一般提供開始**  
  Microsoft FoundryにおけるClaudeが一般提供を開始しました。Azure上でホスティングされ、NVIDIA GB300 Blackwell Ultraを使用することで、エージェントの実験から本番環境への移行が迅速になります。[詳細はこちら](https://azure.microsoft.com/en-us/blog/claude-in-microsoft-foundry-is-now-generally-available/)

- **2026年エージェント信頼性指数の発表**  
  300人の開発者に対する調査結果が発表され、AIエージェントの信頼性に関する見解が示されました。人間の判断がAI時代においても重要なスキルであることが強調されています。[詳細はこちら](https://www.microsoft.com/en-us/microsoft-cloud/blog/2026/06/29/the-2026-agent-confidence-index-where-300-builders-see-real-momentum/)

## コンピューティング
- **Azure Chaos Studioによるアプリケーションのレジリエンス検証**  
  Azure Chaos Studioは、アプリケーションのレジリエンスを検証するためのツールで、障害やネットワークの混乱をシミュレーションすることで、実稼働前に問題を特定することができます。[詳細はこちら](https://azure.microsoft.com/en-us/blog/proving-application-resilience-on-azure-with-chaos-studio/)

- **Azure IaaSのコスト効率を考慮したインフラ設計**  
  組織がインフラを近代化し、重要なワークロードを移行する際に、コスト効率を考慮することが不可欠です。Azure IaaSを使用したインフラ設計・構築・最適化の方法について解説しています。[詳細はこちら](https://azure.microsoft.com/en-us/blog/azure-iaas-how-to-design-build-and-optimize-cloud-infrastructure-for-long-term-cost-optimization-efficiency/)

## その他
- **Azure Filesで現代のLinuxワークロードを加速**  
  Azure Filesは、従来のファイルアクセスを提供しながら、パフォーマンスやデータ保護、セキュリティ、Azureサービスとの統合を実現します。Linuxワークロードの効率を向上させるための便利な機能が紹介されています。[詳細はこちら](https://azure.microsoft.com/en-us/blog/accelerate-modern-linux-workloads-with-azure-files/)
